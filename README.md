# A five-minute Canvas course handoff check

If a colleague is taking over your Canvas course, review one module together before working through the rest. Pick a module with a page, an assignment, and a link to a reading. You can run this check in Canvas for free.

If your reviewer works in Word, [follow the Canvas course to Word guide](https://coursereviewdesk.pages.dev/how-it-works/). Its editable sample shows how the answer key and feedback appear for one quiz question.

1. **Keep a backup.** In the source course, choose **Settings → Export Course Content → Course → Create Export**. Download the finished `.imscc` file and label it with the course and date. Keep that file for a future Canvas import. A Word copy is useful for comments and edits.
2. **Write down what should happen.** Choose one reading, one graded assignment, and the item a student should open next. Note what you expect before you open the destination course. This catches errors that a quick glance at a copied module can miss.
3. **Compare the copies.** Have the incoming instructor check the destination course using Student View where available. Open external readings with the intended student permissions if possible. Record anything you could only verify as the instructor.

| Check | What to compare | Result or next action |
| --- | --- | --- |
| Module order | Can the reviewer find the reading and assignment in the intended sequence? | |
| Assignment instructions | Do the due date written in the instructions, the date shown in Canvas, and the submission directions agree? | |
| Reading access | Can a student open the link with the access they will actually have? | |
| Quiz feedback, if used | Do the correct and incorrect feedback still correspond to the intended answers? Keep answer keys in instructor-only material. | |

For example, a reading link might open for the course author but ask a student to request access. Record the module, the link label, and who will fix the permissions. Keep student names, submissions, and private course files out of public issue trackers.
